# 录入界面识别成功扩散动画

## 假设与决策

1. **动画形式**:从 entry-layout 中心扩散的双层圆形涟漪(24px → 480px,1 秒),用 CSS border 描边实现,避免遮住内容(pointer-events: none)
2. **颜色**:默认主题用 `var(--green)`(与现有识别成功色调一致),Apple 主题用 `var(--blue)`(与 Apple 主题 focus-visible、按钮等强调色一致),浅色主题复用 `--green`
3. **双层涟漪**:两个 ripple span,第二个延迟 150ms,层次感更强,不会过于单调
4. **z-index: 10**:覆盖在 entry-layout 内容之上,但因 `pointer-events: none` 不影响交互
5. **保留现有局部波纹**:`.recognized-name-field.pulse` 不删除,形成"输入框局部波纹 + 全局扩散涟漪"的双层反馈
6. **触发点**:仅在 `applyRecognition` 的成功分支(行 529 后)新增 `setEntryBurst`,与 `setRecognitionPulse` 同步触发,不改动其他逻辑
7. **overlay 容器**:`.entry-layout` 加 `position: relative; overflow: hidden`,确保涟漪不溢出到其他区域。需确认这不会破坏现有 entry-layout 的布局(当前 entry-layout 是 grid,position: relative 不影响 grid 行为)
